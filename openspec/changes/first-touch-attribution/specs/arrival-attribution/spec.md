## ADDED Requirements

### Requirement: Первое касание фиксируется на любой странице входа

При заходе браузера на сайт без действующей записи первого касания система SHALL
записать метки UTM, `yclid`, внешний реферер и путь страницы входа и SHALL
хранить запись 30 дней. Последующие заходы в течение этого срока MUST NOT
перезаписывать её.

#### Scenario: Переход из Дзена без меток

- **WHEN** посетитель впервые приходит со страницы `https://dzen.ru/a/xyz?utm_referrer=foo` на `/content/chto-takoe-kbzhu`
- **THEN** записаны реферер `https://dzen.ru/a/xyz` и страница входа `/content/chto-takoe-kbzhu`

#### Scenario: Переход по рекламе

- **WHEN** посетитель впервые приходит по ссылке с `utm_source=yandex` и `yclid=123`
- **THEN** записаны метка `utm_source = yandex` и `yandex_click_id = 123`

#### Scenario: Повторный заход

- **WHEN** посетитель с записью первого касания возвращается напрямую через 3 дня
- **THEN** запись первого касания не меняется

#### Scenario: Запись истекла

- **WHEN** посетитель возвращается через 31 день по ссылке с другими метками
- **THEN** записывается новое первое касание

#### Scenario: Свой домен не считается реферером

- **WHEN** `document.referrer` указывает на тот же сайт
- **THEN** реферер не записывается

#### Scenario: Прямой заход

- **WHEN** посетитель впервые приходит без реферера и меток
- **THEN** записывается страница входа, а реферер и метки пусты

#### Scenario: Ограничение размера

- **WHEN** значения меток длиннее 200 символов
- **THEN** каждое обрезано до 200 символов, а запись не превышает 1 КБ

### Requirement: Учётная запись получает источник на каждом пути создания

При создании учётной записи паролем, ссылкой из письма или через внешнего
провайдера система SHALL записать источник первого касания в `user_attribution`,
если перенос заявки его не записал. Источник, записанный переносом заявки,
MUST NOT перезаписываться. Отсутствие или повреждение записи первого касания
MUST NOT мешать созданию учётной записи.

#### Scenario: Регистрация паролем без заявки

- **WHEN** посетитель с записью первого касания регистрируется паролем без `lead_token`
- **THEN** у новой учётной записи есть строка `user_attribution` с его реферером и страницей входа

#### Scenario: Регистрация ссылкой из письма

- **WHEN** учётная запись создаётся переходом по ссылке из письма при наличии записи первого касания
- **THEN** у неё есть строка `user_attribution` из этой записи

#### Scenario: Регистрация через внешнего провайдера

- **WHEN** учётная запись создаётся через внешнего провайдера при наличии записи первого касания
- **THEN** у неё есть строка `user_attribution` из этой записи

#### Scenario: Заявка уже записала источник

- **WHEN** при регистрации переносится заявка с метками кампании
- **THEN** строка `user_attribution` содержит метки заявки, а не данные первого касания

#### Scenario: Повреждённая запись

- **WHEN** значение записи первого касания не разбирается
- **THEN** учётная запись создаётся, строки `user_attribution` из неё нет

#### Scenario: Вход в существующую учётную запись

- **WHEN** существующий пользователь входит ссылкой из письма или через провайдера
- **THEN** `user_attribution` не создаётся и не меняется
