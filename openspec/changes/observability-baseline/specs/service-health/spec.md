## ADDED Requirements

### Requirement: Разделение проб живости и готовности

Сервис SHALL предоставлять отдельные эндпоинты проверки живости и готовности. Проба живости MUST NOT обращаться к внешним зависимостям. Проба готовности MUST проверять доступность базы данных.

#### Scenario: База данных недоступна

- **WHEN** база данных недоступна
- **AND** выполняется запрос `GET /ready`
- **THEN** ответ имеет статус `503`
- **AND** тело ответа называет недоступную зависимость

#### Scenario: Живость при недоступной базе

- **WHEN** база данных недоступна
- **AND** выполняется запрос `GET /health`
- **THEN** ответ имеет статус `200`

#### Scenario: Все зависимости доступны

- **WHEN** база данных доступна
- **AND** выполняется запрос `GET /ready`
- **THEN** ответ имеет статус `200`
- **AND** тело содержит состояние проверенных зависимостей

### Requirement: Проба готовности используется балансировщиком и оркестратором

Конфигурация nginx и настройки развёртывания SHALL использовать пробу готовности для решения о направлении трафика, а пробу живости — для решения о перезапуске.

#### Scenario: Инстанс не готов

- **WHEN** проба готовности инстанса возвращает `503`
- **THEN** трафик на этот инстанс не направляется
- **AND** перезапуск контейнера по этой причине не выполняется

### Requirement: Метрики недоступны снаружи

Эндпоинт метрик SHALL быть недоступен из публичной сети.

#### Scenario: Обращение к метрикам извне

- **WHEN** выполняется запрос к `/metrics` через публичный домен
- **THEN** ответ имеет статус `404` или `403`
