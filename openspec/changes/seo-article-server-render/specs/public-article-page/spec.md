## ADDED Requirements

### Requirement: Текст публичной статьи присутствует в HTML первого ответа

Страница публичной статьи SHALL содержать в HTML ответа сервера заголовок статьи
в элементе `h1`, автора, дату публикации и тело статьи, отрендеренное из
Markdown в HTML. Отображение публичной статьи MUST NOT зависеть от выполнения
JavaScript в браузере.

#### Scenario: Запрос без JavaScript

- **WHEN** страница опубликованной статьи с аудиторией `all` запрашивается с выключенным JavaScript
- **THEN** документ содержит `h1` с заголовком статьи и абзацы её текста

#### Scenario: Разметка Markdown

- **WHEN** тело статьи содержит подзаголовок второго уровня и список
- **THEN** HTML ответа содержит элементы `h2` и `li` с этим текстом

#### Scenario: Нет повторного запроса в браузере

- **WHEN** публичная статья открыта в браузере
- **THEN** браузер не запрашивает ту же статью у API повторно

### Requirement: Статья с ограниченной аудиторией не индексируется

Если публичный API статью не вернул, а адрес статьи является UUID, страница
SHALL отдать клиентский просмотр статьи для вошедшего читателя и MUST пометить
страницу `noindex`.

#### Scenario: Статья для клиентов куратора

- **WHEN** запрошен UUID статьи, которой нет в публичном API
- **THEN** страница содержит клиентский просмотр статьи и мета-тег `robots` со значением `noindex`
