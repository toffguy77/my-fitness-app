## Context

`page.tsx` уже серверный компонент и уже вызывает `getPublicArticle` (с
`revalidate: 60`). `ArticleView` — клиентский: сначала пробует
`contentApi.getFeedArticle` (вошедший клиент видит и статьи с аудиторией
`my_clients`/`selected`), при ошибке — публичный API.

`react-markdown@10` синхронный и без хуков, поэтому работает в серверном
компоненте. Страницы и так рендерятся динамически: `middleware.ts` ставит
nonce для CSP на каждый ответ.

## Goals / Non-Goals

**Goals:** текст публичной статьи в HTML первого ответа; один источник разметки.

**Non-Goals:** отметка «прочитано» (её у статей нет: `GetFeedArticle` только
читает); SSR для статей с ограниченной аудиторией — они не для поисковика.

## Decisions

1. **Публичная статья рендерится сервером, ограниченная — клиентом.** Если
   публичный API статью вернул, страница отдаёт `ArticleContent` с данными.
   Если нет, а адрес — UUID, отдаётся `ArticleView` (вдруг это статья для
   клиентов куратора) и `robots: noindex`.
   *Отвергнуто:* рендерить на сервере и ограниченные статьи, передавая cookie
   сессии в API. Сессия живёт в cookie с путём `/api/v1/auth`, на сервер Next
   она не приходит, а поисковику эти статьи всё равно недоступны.
   *Отвергнуто:* гидрировать `ArticleView` начальными данными с сервера.
   Компонент остался бы клиентским целиком ради одного состояния загрузки,
   которое публичной статье не нужно.

2. **`ArticleContent` — чистый компонент без `'use client'`.** Его импортирует и
   серверная страница, и клиентский `ArticleView`; без директивы он может жить
   по обе стороны границы.
   *Отвергнуто:* копировать разметку в страницу. Два места с одинаковыми
   классами `prose` разойдутся при первой правке.

3. **Проверка без JavaScript — сквозным тестом.** Модульный тест проверяет, что
   страница возвращает разметку с `h1` и текстом, но настоящий вопрос аудита —
   что лежит в HTML. Playwright с `javaScriptEnabled: false` отвечает ровно на
   него.

## Risks / Trade-offs

- Markdown рендерится на сервере при каждом запросе → кэш `fetch` на 60 секунд
  уже есть, разбор десятка килобайт Markdown дешевле сетевого запроса.
- В Jest `react-markdown` (ESM) подменяется → тело в модульном тесте
  проверяется через подмену, настоящий рендер — в E2E.
