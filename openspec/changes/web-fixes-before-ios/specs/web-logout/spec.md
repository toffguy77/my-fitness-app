## ADDED Requirements

### Requirement: Выход из профиля завершает сессию на сервере

«Выйти из аккаунта» в профиле SHALL вызывать `POST /api/v1/auth/logout`, затем очищать токен и кэш профиля и переходить на `/auth`; ошибка сети MUST NOT мешать локальному выходу.

#### Scenario: Выход

- **WHEN** пользователь нажимает «Выйти из аккаунта»
- **THEN** отправлен `POST /auth/logout`
- **AND** после перехода на `/auth` запрос `POST /auth/refresh` не возвращает новую сессию

#### Scenario: Нет сети

- **WHEN** `POST /auth/logout` завершился ошибкой сети
- **THEN** пользователь всё равно оказывается на `/auth` без токена в памяти
