## ADDED Requirements

### Requirement: Переписка куратора открывается по клиенту и не висит в загрузке

`/curator/chat/<clientId>` SHALL получать переписку через `GET /api/v1/conversations/by-participant/:clientId`; ответ `404` MUST показывать «Переписка с клиентом не найдена» со ссылкой на карточку клиента вместо вечного «Загрузка…».

#### Scenario: Переписки нет

- **WHEN** куратор открывает переписку клиента, с которым переписки нет
- **THEN** показано «Переписка с клиентом не найдена» и ссылка «Открыть карточку клиента»

#### Scenario: Переписка есть

- **WHEN** куратор открывает переписку своего клиента
- **THEN** отправлен один запрос `by-participant`, а не `GET /conversations`
