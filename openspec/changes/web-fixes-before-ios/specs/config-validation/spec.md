## MODIFIED Requirements

### Requirement: Диагностика конфигурации через health-эндпоинт

`GET /ready` SHALL возвращать поле `features` — объект, в котором ключ соответствует опциональной возможности, а значение — булев признак её включённости. `GET /health` — проба живости — MUST NOT обращаться к зависимостям и не обязан перечислять возможности.

#### Scenario: Запрос состояния возможностей

- **WHEN** выполняется `GET /ready` на инстансе без заданных S3-ключей и с заданным `OPENROUTER_API_KEY`
- **THEN** ответ содержит `features` с истинным значением для распознавания еды и ложным для загрузок в S3

#### Scenario: Проба живости

- **WHEN** выполняется `GET /health`
- **THEN** ответ содержит `status`, `timestamp`, `environment`, `version` и не зависит от доступности базы
