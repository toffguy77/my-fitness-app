## 1. Решение об источнике

- [ ] 1.1 **Блокирует остальное.** Выбрать источник норм и записать выбор: МР 2.3.1.0253-21, EFSA DRV или иной. Проверка: источник и его версия названы в PR; для трёх произвольных нутриентов приведена цифра из источника и ссылка на раздел.
- [ ] 1.2 Определить по выбранному источнику, зависят ли нормы от пола и возраста. Проверка: ответ записан. Если зависят — раздел 2 расширяется миграцией схемы, и это отмечено в предложении до начала работы.

## 2. Схема

- [ ] 2.1 Добавить колонки источника и его версии в `nutrient_recommendations`, обязательные. Проверка: миграция применяется и откатывается на чистой базе; вставка строки без источника отклоняется базой.
- [ ] 2.2 Отдавать источник в ответе рекомендаций. Проверка: тест сценария «Норма прочитана».
- [ ] 2.3 **Только если нормы зависят от групп (задача 1.2):** миграция схемы под нормы по полу и возрасту, правка запроса и ответа. Проверка: нормы для двух разных профилей различаются; тесты обоих случаев.

## 3. Наполнение

- [ ] 3.1 Наполнить справочник по выбранному источнику: название, категория, единица, суточная норма, источник. Проверка: количество строк совпадает с количеством нутриентов в источнике; выборочная сверка трёх цифр с источником приложена к PR.
- [ ] 3.2 Заполнить тексты пояснений там, где источник их даёт; где не даёт — оставить пустыми, а не придумывать. Проверка: ни одно пояснение не написано от себя.
- [ ] 3.3 Сверить номера миграций с целевой базой. Проверка: мигратор сверяет только номер, и занятый номер означает молча непримененную миграцию.

## 4. Сторож непустоты

- [ ] 4.1 Завести проверку, падающую на пустом справочнике. Проверка: тесты сценариев «Справочник заполнен» и «Справочник пуст».
- [ ] 4.2 Убедиться, что сервис поднимается и с пустым справочником. Проверка: тест сценария «Сервис поднимается и с пустым справочником» — рекомендации отвечают пустым набором, остальной продукт работает.

## 5. Проверка целиком

- [ ] 5.1 Прогнать всё. Проверка: `npx jest`, `npm run type-check`, `npm run lint`, `go test ./...`, интеграционные на чистой базе и три скрипта целостности проходят.
- [ ] 5.2 Открыть вкладку рекомендаций в браузере живым аккаунтом с записями о еде. Проверка: нутриенты видны, потребление совпадает с записями дня. Это та проверка, которую `unreachable-routes` выполнить не мог — показывать было нечего.
