## ADDED Requirements

### Requirement: Единый контракт постраничной выдачи

Эндпоинты, возвращающие коллекции, SHALL принимать параметры `limit` и `offset` и возвращать объект с элементами страницы, общим количеством, применённым значением `limit` и применённым `offset`. Значение `limit` по умолчанию — 20, предельное значение — 100.

#### Scenario: Запрос без параметров

- **WHEN** клиент запрашивает коллекцию без параметров постраничной выдачи
- **THEN** ответ содержит не более 20 элементов
- **AND** ответ содержит общее количество элементов

#### Scenario: Запрос сверх предела

- **WHEN** клиент запрашивает коллекцию с `limit=1000`
- **THEN** ответ содержит не более 100 элементов
- **AND** поле применённого `limit` в ответе равно 100

#### Scenario: Запрос следующей страницы

- **WHEN** клиент запрашивает коллекцию с `offset`, равным размеру первой страницы
- **THEN** ответ содержит следующие элементы, не пересекающиеся с первой страницей при неизменном наборе данных

#### Scenario: Некорректные значения параметров

- **WHEN** клиент передаёт отрицательный `offset` или нечисловой `limit`
- **THEN** применяются значения по умолчанию, и запрос обрабатывается успешно

### Requirement: Отсутствие неограниченных выборок

Обработчики коллекций MUST NOT выполнять запросы к базе данных без ограничения количества возвращаемых строк. Запросы, участвующие в формировании страницы, MUST ограничиваться идентификаторами текущей страницы и не выполнять агрегацию по всей таблице.

#### Scenario: Список пользователей в административном разделе

- **WHEN** администратор запрашивает список пользователей
- **THEN** выполняемые запросы содержат ограничение количества строк
- **AND** сведения о последнем входе запрашиваются только для пользователей текущей страницы

#### Scenario: Проверка отсутствия неограниченных запросов

- **WHEN** выполняется проверка обработчиков коллекций на наличие запросов без ограничения количества строк
- **THEN** таких запросов не обнаружено
