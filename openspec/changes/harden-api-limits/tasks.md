- [x] 1.2 Зафиксировать белые списки типов по результатам 1.1, включая решение по HEIC. Проверка: списки согласованы в PR. **Списки: JPEG, PNG, WebP для фотографий; плюс GIF для медиа статей; плюс PDF для вложений чата — как и было.** **Решение по HEIC: не принимать, но объяснять.** Формат и раньше не принимался — Go его не распознаёт вовсе и возвращает `application/octet-stream`, то есть человек получал «неподдерживаемый тип файла» про только что снятую фотографию. Настоящий приём HEIC потребовал бы декодера (libheif через cgo) и конвертации на сервере; сочтено несоразмерным, потому что при съёмке и выборе из галереи iOS сам отдаёт JPEG, а HEIC доходит только через «Файлы». Поэтому: поля загрузки перечисляют типы вместо `image/*` — «Файлы» такой файл отфильтруют и выбрать его будет нельзя; а если файл всё же дойдёт, детектор узнаёт его по бренду ISO-BMFF и отвечает тем, что можно сделать. Тест сверяет `accept` на формах с белым списком сервера: разъехаться они больше не могут.
