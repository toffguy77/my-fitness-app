## ADDED Requirements

### Requirement: Ссылки на статьи присутствуют в HTML ленты

Страница ленты `/content` SHALL содержать в HTML ответа сервера ссылки на первые
20 опубликованных публичных статей, отсортированных по дате публикации, с их
заголовками. Ссылки MUST вести на канонический адрес статьи.

#### Scenario: Запрос без JavaScript

- **WHEN** `/content` запрашивается с выключенным JavaScript и опубликованы публичные статьи
- **THEN** документ содержит ссылки `a[href^="/content/"]` с заголовками этих статей

#### Scenario: Больше двадцати статей

- **WHEN** опубликовано больше 20 публичных статей
- **THEN** HTML содержит ровно 20 карточек и кнопку догрузки

#### Scenario: API недоступен при рендере

- **WHEN** запрос ленты на сервере завершился ошибкой
- **THEN** страница отвечает успешно, а лента загружается в браузере

### Requirement: Гость не запрашивает ленту повторно

Если лента получена на сервере, клиент SHALL NOT повторно запрашивать ту же
публичную ленту без рубрики для посетителя без учётной записи.

#### Scenario: Гость открывает ленту

- **WHEN** посетитель без учётной записи открывает `/content`
- **THEN** публичная лента без рубрики не запрашивается браузером, а карточки видны сразу

#### Scenario: Смена рубрики

- **WHEN** гость выбирает рубрику
- **THEN** браузер запрашивает ленту этой рубрики

#### Scenario: Вошедший пользователь

- **WHEN** открывает ленту пользователь с учётной записью
- **THEN** браузер запрашивает его персональную ленту и показывает её вместо публичной
