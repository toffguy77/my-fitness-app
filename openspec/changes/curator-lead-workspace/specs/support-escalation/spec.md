## MODIFIED Requirements

### Requirement: Разбор эскалированных разговоров

Разговоры, ожидающие человека, SHALL разбираться кураторами. Ответ куратора MUST доходить до собеседника в том канале, из которого он пришёл.

#### Scenario: Куратор видит очередь

- **WHEN** куратор открывает раздел разговоров
- **THEN** он видит разговоры, ожидающие человека, начиная с самых старых
- **AND** разговоры из разных каналов находятся в одной очереди

#### Scenario: Куратор отвечает в разговор из Telegram

- **WHEN** куратор отвечает в разговор, пришедший из Telegram
- **THEN** ответ отправляется собеседнику в Telegram

#### Scenario: Куратор отвечает в разговор из браузера

- **WHEN** куратор отвечает в разговор, пришедший из браузера
- **THEN** ответ становится доступен посетителю при обращении с его токеном

#### Scenario: Автор ответа сохраняется

- **WHEN** куратор отвечает в разговор
- **THEN** в сообщении сохраняется, какой именно куратор его написал

#### Scenario: Закрытие разговора

- **WHEN** куратор закрывает разговор
- **THEN** сохраняется время закрытия и кто его закрыл
