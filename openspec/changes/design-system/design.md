## Context

Направление выбрано из трёх вариантов, отрисованных на дашборде и дневнике
(«Пульс» — данные и тёмная тема, «Ясность» — точность и системные списки,
«Коуч» — куратор и смысл): основа «Коуч», из «Ясности» — остаток в граммах,
панель быстрого ввода и недельные точки, из «Пульса» — запись в одно касание
с карточки питания.

## Decisions

### Источник токенов — W3C DTCG JSON, сборка своим скриптом

Формат DTCG читают Style Dictionary, Tokens Studio, Figma Variables — переход на
любой из них не меняет источник. Сборка — 300 строк без зависимостей
(`packages/design-tokens/scripts/build.mjs`), потому что ей нужно то, что
готовые форматы не дают: одна таблица CSS со светлой темой в `:root` и тёмной
под `prefers-color-scheme` и `[data-theme]`, тема Tailwind из тех же имён и
проверка контраста.

Отвергнуто:
- **Style Dictionary сейчас.** Для веба всё равно пришлось бы писать свои
  форматы (две темы в одном файле, тема Tailwind), а мобильный стек не выбран.
  Подключается, когда он выбран: источник уже в его формате.
- **Токены в TypeScript-объекте** (`styles/tokens/*.ts`, как было). Не читаются
  инструментами дизайна и мобильными сборками; прежний модуль не импортировал
  ни один файл.
- **Только CSS-переменные без пакета.** Значения нужны и там, где CSS нет:
  картинка OG, `global-error`, будущие iOS/Android.

### Роли вместо палитры; палитра Tailwind отключена

Классы — только роли (`bg-surface`, `text-fg-muted`), тема переключает роли.
`--color-*: initial` убирает палитру из сборки, ESLint называет нарушение сразу.

Отвергнуто:
- **`dark:`-варианты на каждом элементе.** Удваивает разметку и забывается
  ровно там, где не проверили.
- **Оставить палитру и запретить только линтером.** Класс, пропущенный
  линтером (строка, собранная из частей), работал бы и молча расходился с
  темой; без палитры он не работает вовсе и виден на экране.

### Остаток вместо процента

Главное число — остаток (ккал, граммы), доля — подписью «N из M». Превышение —
«+N сверх нормы» без перекраски (требование macro-colour-system).

Отвергнуто: **процент под каждым показателем** (было) — «67%» не отвечает на
вопрос «что съесть на ужин».

### Неделя точками вместо линейного графика

Точка на день, высота — отклонение от нормы, полоса — коридор ±5%. Отвергнуто:
**две линии «цель/факт»** (было) — тот же ответ приходилось выводить из их
пересечения.

### Шрифты своими копиями

`@fontsource-variable/literata`, `@fontsource-variable/golos-text`. Отвергнуто:
**`next/font/google`** — сборка ходит в Google при каждом билде, а с серверов
сборки он бывает недоступен; **системный шрифт** — у SF и Roboto нет засечек
для голоса куратора.

### Справочник — страница приложения, а не Storybook

`/design-system` собирает те же компоненты на примерных данных в обеих темах.
Отвергнуто: **Storybook** — второй сборщик и вторая конфигурация Tailwind,
которые разъедутся с приложением; появится смысл, когда компонентов станет
больше десятка-двух.

## Risks / Trade-offs

- Ветки, начатые до этого изменения, конфликтуют по классам. Смягчение:
  кодмод остаётся в репозитории, документация описывает порядок.
- Кодмод переводит по оттенку, а не по смыслу: синий информационный блок стал
  брендовым (`primary-soft`). Экраны, кроме дашборда и дневника, проверены
  глазами не все.
- Тема выбирается системой; настройки темы в профиле нет (механизм —
  `shared/theme/theme.ts`).
