# Spec Delta

## ADDED Requirements

### Requirement: Переписка с куратором требует действующего права

Отправка сообщения в переписке клиента с куратором SHALL требовать действующего
права на работу с куратором и SHALL отвергаться с `403` при его отсутствии. Обе
стороны подчиняются правилу одинаково: куратор, продолжающий переписку с
клиентом без права, работает бесплатно, не зная об этом.

Проверка SHALL выполняться на стороне API. Скрытие входа в интерфейсе
MUST NOT быть единственным препятствием: платный доступ, закрытый только
интерфейсом, открыт любому, кто обратится к API напрямую.

Чтение прежних сообщений SHALL оставаться разрешённым.

#### Scenario: Клиент без права отправляет сообщение

- **WHEN** клиент без действующего права обращается к API отправки сообщения
- **THEN** ответ `403`

#### Scenario: Право истекло

- **WHEN** право клиента прекращено по истечении предельной даты
- **AND** клиент обращается к API отправки сообщения
- **THEN** ответ `403`

#### Scenario: Куратор пишет клиенту без права

- **WHEN** куратор отправляет сообщение клиенту, у которого право прекращено
- **THEN** ответ `403`

#### Scenario: Право действует

- **WHEN** клиент с действующим правом отправляет сообщение
- **THEN** сообщение принято

#### Scenario: Чтение истории без права

- **WHEN** клиент без действующего права запрашивает сообщения своей переписки
- **THEN** сообщения возвращены
