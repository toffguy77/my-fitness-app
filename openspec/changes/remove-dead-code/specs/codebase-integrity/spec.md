## ADDED Requirements

### Requirement: Отсутствие зарегистрированных нереализованных эндпоинтов

API MUST NOT содержать зарегистрированных маршрутов, обработчики которых возвращают заранее заданные литеральные данные вместо обращения к источнику данных.

#### Scenario: Обращение к удалённой группе маршрутов питания

- **WHEN** выполняется запрос `GET /api/v1/nutrition/entries` с валидным токеном
- **THEN** API отвечает статусом `404`

#### Scenario: Проверка отсутствия модуля-заглушки

- **WHEN** выполняется поиск по `apps/api/internal/modules` комментариев вида `TODO: Implement` в файлах сервисов, чьи маршруты зарегистрированы
- **THEN** совпадений не найдено

### Requirement: Единственная конфигурация сборки фронтенда

Репозиторий SHALL содержать ровно один файл конфигурации Next.js. Утверждения о настройках сборки в `CLAUDE.md` MUST соответствовать содержимому этого файла.

#### Scenario: Проверка количества конфигураций

- **WHEN** выполняется поиск файлов `next.config.*` вне `node_modules`
- **THEN** найден ровно один файл — `apps/web/next.config.ts`

#### Scenario: Согласованность документации и конфигурации

- **WHEN** сравнивается значение флага React Compiler в `apps/web/next.config.ts` с утверждением в `CLAUDE.md`
- **THEN** они совпадают

### Requirement: Единственная реализация клиента WebSocket

Фронтенд SHALL содержать одну реализацию подключения к WebSocket. Приложение MUST открывать не более одного соединения на аутентифицированного пользователя независимо от количества смонтированных экранов, использующих чат.

#### Scenario: Несколько потребителей событий чата

- **WHEN** одновременно смонтированы несколько компонентов, подписанных на события чата
- **THEN** открыто ровно одно соединение WebSocket

#### Scenario: Проверка отсутствия дубликата

- **WHEN** выполняется поиск по `apps/web/src` вызовов конструктора `WebSocket`
- **THEN** найдено не более одного места вызова

### Requirement: Публичные переменные окружения объявляются вместе с использованием

Каждая переменная с префиксом `NEXT_PUBLIC_`, объявленная в файлах окружения фронтенда, SHALL быть прочитана кодом в `apps/web/src`. Переменные, содержащие секреты, MUST NOT иметь префикс `NEXT_PUBLIC_`.

#### Scenario: Объявлена неиспользуемая публичная переменная

- **WHEN** в файле окружения фронтенда объявлена переменная `NEXT_PUBLIC_*`, отсутствующая в исходниках
- **THEN** проверка целостности в CI завершается с ошибкой, называющей эту переменную

#### Scenario: Секрет с публичным префиксом

- **WHEN** в файлах окружения присутствует переменная с префиксом `NEXT_PUBLIC_` и именем, содержащим `KEY`, `SECRET` или `TOKEN`
- **THEN** проверка целостности в CI завершается с ошибкой
