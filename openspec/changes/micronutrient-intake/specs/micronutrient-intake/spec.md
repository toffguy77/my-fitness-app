## ADDED Requirements

### Requirement: Потребление считается по записям дня

Потребление нутриента SHALL считаться суммой по записям дня, у которых содержание этого нутриента известно.

#### Scenario: Все записи знают нутриент

- **WHEN** у всех записей дня известно содержание нутриента
- **THEN** потребление равно сумме по всем записям, пересчитанной на съеденные граммы

#### Scenario: Часть записей знает нутриент

- **WHEN** содержание известно у части записей дня
- **THEN** потребление равно сумме по этой части
- **AND** остальные записи в сумму не входят

#### Scenario: Ни одна запись не знает нутриент

- **WHEN** содержание не известно ни у одной записи
- **THEN** потребление не приходит вовсе
- **AND** ноль как измеренное значение не приходит

#### Scenario: Записей о еде нет

- **WHEN** за день нет записей
- **THEN** потребление не приходит

### Requirement: Рядом с величиной видно, по чему она посчитана

Ответ SHALL сообщать, сколько записей дня участвовало в подсчёте и сколько записей всего.

#### Scenario: Посчитано по части записей

- **WHEN** в подсчёт вошли не все записи дня
- **THEN** приходит число участвовавших записей и общее число записей
- **AND** человеку показано, по какой части дня посчитана величина

#### Scenario: Посчитано по всем записям

- **WHEN** в подсчёт вошли все записи дня
- **THEN** покрытие показывает это, и оговорки не появляется

### Requirement: Единица величины совпадает с единицей нормы

Потребление SHALL приходить в той же единице, в которой задана норма нутриента.

#### Scenario: Норма в миллиграммах

- **WHEN** норма нутриента задана в миллиграммах, а справочник продуктов хранит граммы на 100 г
- **THEN** потребление приходит в миллиграммах

#### Scenario: Норма в микрограммах

- **WHEN** норма задана в микрограммах
- **THEN** потребление приходит в микрограммах

### Requirement: Невозможное значение не используется

Содержание нутриента, превышающее массу самого продукта, MUST NOT участвовать в подсчёте.

#### Scenario: Значение больше массы продукта

- **WHEN** у продукта указано больше 100 г нутриента на 100 г продукта
- **THEN** эта запись в подсчёт не входит
- **AND** она считается записью без известного содержания

#### Scenario: Значение на границе возможного

- **WHEN** значение не превышает 100 г на 100 г
- **THEN** оно участвует в подсчёте

### Requirement: Где считать нечем, поведение не меняется

Нутриент, для которого справочник продуктов не хранит содержание, SHALL показываться нормой без прогресса.

#### Scenario: Нутриента нет в справочнике продуктов

- **WHEN** запрашивается нутриент, содержание которого продукты не хранят
- **THEN** приходит норма и не приходит потребление
