# Spec Delta

## Purpose

Определяет, что строка в списке разговоров сообщает об активности в этом
разговоре: когда там последний раз писали и что показано, если не писали вовсе.

## ADDED Requirements

### Requirement: Время в строке означает последнее сообщение

Время, показанное в строке разговора, SHALL быть временем последнего сообщения в
нём. Время создания разговора MUST NOT показываться на его месте.

#### Scenario: В разговоре есть сообщения

- **WHEN** в разговоре есть сообщения
- **THEN** показано время последнего из них

#### Scenario: Разговор создан сегодня, сообщений нет

- **WHEN** разговор создан и ни одного сообщения в нём нет
- **THEN** время не показано
- **AND** показано, что сообщений нет

#### Scenario: Первое сообщение отправлено

- **WHEN** в пустом разговоре появилось первое сообщение
- **THEN** показано время этого сообщения

### Requirement: Разговор без сообщений не поднимается в списке

Порядок списка SHALL ставить разговоры без сообщений после разговоров, в которых
писали. Время создания разговора MUST NOT влиять на его место.

#### Scenario: Пустой разговор создан позже переписки

- **WHEN** разговор без сообщений создан позже, чем пришло последнее сообщение в другом разговоре
- **THEN** разговор с сообщениями стоит выше

#### Scenario: Несколько пустых разговоров

- **WHEN** в списке несколько разговоров без сообщений
- **THEN** все они стоят после разговоров с сообщениями

#### Scenario: Непрочитанные остаются первыми

- **WHEN** в разговоре есть непрочитанные сообщения
- **THEN** он стоит выше разговоров без непрочитанных
- **AND** выше разговоров без сообщений
