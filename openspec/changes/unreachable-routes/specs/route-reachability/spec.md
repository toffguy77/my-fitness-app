## ADDED Requirements

### Requirement: Маршрут обязан вызываться или быть объявлен исключением

Проверка контракта API SHALL завершаться неуспехом, если зарегистрированный маршрут не вызывается из фронтенда и не имеет записи в реестре исключений.

#### Scenario: Маршрут вызывается

- **WHEN** зарегистрированный маршрут вызывается из кода фронтенда
- **THEN** проверка не требует для него записи в реестре

#### Scenario: Маршрут не вызывается и не объявлен

- **WHEN** зарегистрирован маршрут, которого не зовёт ни фронтенд, ни проверки
- **AND** записи о нём в реестре нет
- **THEN** проверка завершается неуспехом и называет маршрут

#### Scenario: Маршрут объявлен исключением

- **WHEN** маршрут не вызывается, но имеет запись в реестре с причиной
- **THEN** проверка проходит

#### Scenario: Запись без причины

- **WHEN** запись в реестре не содержит причины
- **THEN** проверка завершается неуспехом

#### Scenario: Устаревшая запись

- **WHEN** маршрут, объявленный исключением, начинает вызываться из фронтенда
- **THEN** проверка сообщает, что запись больше не нужна

#### Scenario: Запись о несуществующем маршруте

- **WHEN** в реестре есть запись о маршруте, которого больше нет в таблице маршрутов
- **THEN** проверка сообщает об этом

### Requirement: Сопоставление путей понимает способы, которыми фронтенд их пишет

Проверка SHALL считать маршрут вызванным независимо от того, записан путь литералом или собран из базовой константы.

#### Scenario: Путь записан литералом

- **WHEN** фронтенд обращается к пути полной строкой, включая префикс версии
- **THEN** маршрут считается вызванным

#### Scenario: Путь записан без префикса версии

- **WHEN** фронтенд обращается к пути без префикса версии, который подставляет клиент
- **THEN** маршрут считается вызванным

#### Scenario: Путь собран из базовой константы

- **WHEN** фронтенд объявляет базовую константу и обращается к пути через неё
- **THEN** маршрут считается вызванным

#### Scenario: Параметр в пути

- **WHEN** путь маршрута содержит параметр, а фронтенд подставляет на его место значение
- **THEN** маршрут считается вызванным по статической части пути

### Requirement: Проверка выполняется в конвейере

Проверка SHALL выполняться в CI той же командой, что и локально.

#### Scenario: Запуск в CI

- **WHEN** конвейер выполняет проверки целостности
- **THEN** проверка достижимости маршрутов выполняется вместе с ними и её неуспех останавливает конвейер
