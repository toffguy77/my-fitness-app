## ADDED Requirements

### Requirement: Клиентские переходы отправляются как просмотры

Система SHALL отправлять в счётчик просмотр страницы при каждом переходе, выполненном без перезагрузки.

#### Scenario: Переход между экранами

- **WHEN** посетитель переходит с одного пути на другой без перезагрузки страницы
- **THEN** в счётчик отправляется ровно один просмотр с новым путём

#### Scenario: Первый просмотр не задваивается

- **WHEN** счётчик инициализируется при загрузке страницы
- **THEN** просмотр этой страницы не отправляется отдельно от инициализации

#### Scenario: Строка запроса сохраняется

- **WHEN** посетитель приходит на путь со строкой запроса и переходит дальше
- **THEN** отправленный просмотр содержит путь и строку запроса перехода

#### Scenario: Повторный переход на тот же путь

- **WHEN** путь перехода совпадает с текущим
- **THEN** дополнительный просмотр не отправляется

#### Scenario: Согласия нет

- **WHEN** решение о согласии отсутствует или посетитель отказался
- **THEN** просмотры при переходах не отправляются
- **AND** переходы работают обычным образом

#### Scenario: Счётчика нет

- **WHEN** идентификатор счётчика отсутствует в окружении
- **THEN** просмотры не отправляются
- **AND** страница отрисовывается без ошибок

#### Scenario: Счётчик не загрузился

- **WHEN** скрипт счётчика заблокирован расширением или ещё не пришёл
- **THEN** переход не вызывает ошибки

### Requirement: Ввод пользователя не покидает приложение

Счётчик MUST NOT быть настроен на запись содержимого экрана и ввода в поля формы.

#### Scenario: Состав опций инициализации

- **WHEN** счётчик инициализируется
- **THEN** запись сессий в опциях выключена
- **AND** карта кликов, отслеживание внешних ссылок и уточнённый показатель отказов включены

#### Scenario: Сбор без JavaScript отсутствует

- **WHEN** страница отрисована
- **THEN** разметка не содержит изображения-пикселя счётчика, работающего без JavaScript

#### Scenario: Отказ по-прежнему выключает счётчик

- **WHEN** посетитель отказался от аналитических куки
- **THEN** скрипт счётчика не отрисовывается
