## ADDED Requirements

### Requirement: Событие глубины прокрутки посадочной страницы

Система SHALL регистрировать достижение фиксированных порогов прокрутки посадочной страницы, по одному разу за визит на каждый порог.

#### Scenario: Порог достигнут

- **WHEN** посетитель прокручивает посадочную страницу до четверти, половины, трёх четвертей или конца
- **THEN** регистрируется событие глубины прокрутки со значением достигнутого порога

#### Scenario: Повторное достижение порога

- **WHEN** посетитель прокручивает страницу назад и снова достигает уже отправленного порога
- **THEN** повторное событие не регистрируется

#### Scenario: Один переход через несколько порогов

- **WHEN** посетитель прокручивает страницу до конца одним движением
- **THEN** регистрируется каждый пройденный порог

#### Scenario: Страница короче экрана

- **WHEN** посадочная страница целиком видна без прокрутки
- **THEN** регистрируется достижение конечного порога

### Requirement: Значения свойства проверяются по объявленному набору

Свойство события, для которого объявлен набор допустимых значений, MUST отклоняться сервером при значении вне набора.

#### Scenario: Значение вне набора

- **WHEN** принимается событие глубины прокрутки со значением, не входящим в набор
- **THEN** событие отклоняется как не прошедшее проверку

#### Scenario: Число и строка — один ответ

- **WHEN** значение порога приходит числом или строкой с тем же печатным видом
- **THEN** оба принимаются

#### Scenario: Свойство без объявленного набора

- **WHEN** принимается событие со свойством, для которого набор не объявлен
- **THEN** любое скалярное значение принимается
