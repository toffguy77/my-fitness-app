## ADDED Requirements

### Requirement: Интерфейс выбирается по роли из ответа сервера

Приложение SHALL выбирать оболочку по `role` из `GET /auth/me`: `client` — вкладки «Сегодня», «Дневник», «Меню», «Ещё», а переписка с куратором — значок в шапке рядом с профилем, не вкладка; `coordinator` — «Клиенты», «Чаты», «Заявки», «Обращения»; `super_admin` — «Заявки», «Обращения». Пока роль неизвестна, MUST показываться экран загрузки, а не оболочка по умолчанию.

#### Scenario: Куратор входит

- **WHEN** `GET /auth/me` возвращает `role: coordinator`
- **THEN** показан таббар из вкладок «Клиенты», «Чаты», «Заявки», «Обращения»

#### Scenario: Клиент входит

- **WHEN** `GET /auth/me` возвращает `role: client`
- **THEN** показан таббар из вкладок «Сегодня», «Дневник», «Меню», «Ещё», а в шапке «Сегодня» — значок чата с куратором

#### Scenario: Суперадмин входит

- **WHEN** `GET /auth/me` возвращает `role: super_admin`
- **THEN** показан таббар из вкладок «Заявки» и «Обращения», а не клиентский интерфейс

#### Scenario: Роль ещё не пришла

- **WHEN** ответ `/auth/me` ещё не получен и кэша профиля нет
- **THEN** не показан ни один таббар

#### Scenario: Нет сети, есть кэш профиля

- **WHEN** приложение запущено без сети, а в кэше профиль с ролью `client`
- **THEN** показана клиентская оболочка с подписью «Нет подключения»

### Requirement: Неизвестная роль не получает чужой интерфейс

Роль, не перечисленная выше, SHALL получать экран «Этот раздел доступен в веб-версии» со ссылкой на сайт и кнопкой «Выйти».

#### Scenario: Новая серверная роль

- **WHEN** `/auth/me` возвращает роль `nutritionist`
- **THEN** показан экран «Этот раздел доступен в веб-версии»

### Requirement: Устаревшее приложение просит обновиться

Если версия приложения ниже `ios.min_supported_version` из `GET /config`, приложение SHALL показывать блокирующий экран «Обновите приложение» с кнопкой App Store. Недоступность `/config` MUST NOT блокировать приложение.

#### Scenario: Версия ниже минимальной

- **WHEN** версия приложения 1.0.0, а `min_supported_version` — 1.2.0
- **THEN** показан экран «Обновите приложение»

#### Scenario: Конфигурация недоступна

- **WHEN** `/config` не ответил
- **THEN** приложение работает с последней сохранённой конфигурацией
