## ADDED Requirements

### Requirement: Запрос на удаление аккаунта

Аутентифицированный пользователь SHALL иметь возможность запросить удаление своего аккаунта. Запрос MUST требовать подтверждения текущим паролем. После успешного запроса аккаунт переходит в состояние ожидания удаления, а все сессии пользователя завершаются.

#### Scenario: Успешный запрос на удаление

- **WHEN** пользователь вызывает `POST /api/v1/users/me/deletion` с корректным текущим паролем
- **THEN** API отвечает статусом `202`
- **AND** у пользователя проставляется время запроса удаления
- **AND** все refresh-токены пользователя отозваны
- **AND** в ответе указана дата необратимого удаления

#### Scenario: Неверный пароль

- **WHEN** пользователь вызывает запрос на удаление с неверным паролем
- **THEN** API отвечает статусом `401`
- **AND** состояние аккаунта не меняется

#### Scenario: Повторный запрос

- **WHEN** пользователь, уже запросивший удаление, вызывает запрос повторно
- **THEN** API отвечает статусом `409`
- **AND** дата необратимого удаления не сдвигается

### Requirement: Период отмены удаления

Необратимое удаление SHALL выполняться не ранее чем через 30 дней после запроса. В течение этого периода пользователь MUST иметь возможность отменить удаление после успешного входа.

#### Scenario: Вход в период ожидания

- **WHEN** пользователь в состоянии ожидания удаления успешно проходит аутентификацию
- **THEN** API возвращает признак ожидания удаления и дату необратимого удаления
- **AND** доступ к остальным эндпоинтам приложения не предоставляется

#### Scenario: Отмена удаления

- **WHEN** пользователь в состоянии ожидания удаления вызывает `DELETE /api/v1/users/me/deletion`
- **THEN** время запроса удаления очищается
- **AND** пользователь получает полный доступ к приложению

#### Scenario: Истечение периода ожидания

- **WHEN** с момента запроса удаления прошло более 30 дней
- **THEN** фоновая задача выполняет необратимое удаление аккаунта

### Requirement: Деактивация аккаунта в период ожидания

Аккаунт в состоянии ожидания удаления SHALL быть недоступен для всех операций, кроме аутентификации, отмены удаления и получения ранее сформированной выгрузки. Данные такого пользователя MUST NOT отображаться куратору и MUST NOT участвовать в рассылке уведомлений и писем.

#### Scenario: Обращение к защищённому эндпоинту

- **WHEN** пользователь в состоянии ожидания удаления обращается к любому эндпоинту приложения, кроме разрешённых
- **THEN** API отвечает статусом `403` с признаком ожидания удаления

#### Scenario: Список клиентов куратора

- **WHEN** куратор запрашивает список своих клиентов
- **THEN** клиенты в состоянии ожидания удаления в списке отсутствуют

#### Scenario: Уведомления не создаются

- **WHEN** наступает событие, порождающее уведомление для пользователя в состоянии ожидания удаления
- **THEN** уведомление не создаётся и письмо не отправляется

### Requirement: Полнота необратимого удаления

Необратимое удаление SHALL обработать все данные пользователя согласно явно объявленной для каждой таблицы стратегии: удаление, анонимизация или сохранение обезличенного агрегата. Файлы пользователя во всех хранилищах MUST быть удалены.

#### Scenario: Персональные данные удалены

- **WHEN** выполнено необратимое удаление аккаунта
- **THEN** записи дневника питания, воды, метрик, задач, планов, уведомлений и пользовательских продуктов этого пользователя отсутствуют
- **AND** объекты во всех хранилищах файлов, относящиеся к этому пользователю, отсутствуют
- **AND** адрес электронной почты, имя и аватар пользователя стёрты

#### Scenario: Переписка сохранена обезличенной

- **WHEN** выполнено необратимое удаление аккаунта клиента
- **THEN** сообщения в переписке с куратором сохранены
- **AND** отправитель этих сообщений указывает на технического удалённого пользователя
- **AND** куратор может открыть переписку без ошибок

#### Scenario: Полнота стратегий проверяется автоматически

- **WHEN** в схеме базы данных существует таблица со ссылкой на пользователя, для которой не объявлена стратегия удаления
- **THEN** тест полноты стратегий завершается с ошибкой, называющей эту таблицу
