Проверка: ручная проверка пройдена. **Пройден 2026-09-14 после трёх дефектов, каждый из которых прятался за предыдущим.** Первый: профиль искали в ответе на обмен кода, а VK ID отдаёт его отдельным запросом к `oauth2/user_info` — проверки это пропустили, потому что подделывали тот же неверный протокол. Второй: VK ID выдаёт код вместе с `device_id` и без него токен не отдаёт; поля нет в обычном OAuth, и отказ приходил телом с кодом 200, который мы не читали — любая причина выглядела как «нет токена». Третий: введённый человеком адрес записывался в структуру в памяти, а не в попытку входа, и шаг подтверждения находил её без адреса, отвечая «попытка истекла» через тринадцать секунд после ввода. Третий дефект срабатывает только у провайдеров, не отдающих адрес, — поэтому вход через Яндекс работал всё это время.
