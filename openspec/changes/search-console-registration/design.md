## Context

Подтверждение прав в Вебмастере — DNS-запись TXT, она живёт вне репозитория.
API Вебмастера требует OAuth-токен владельца, в окружении проекта его нет.

## Decisions

1. **Без мета-тега.** Два способа подтверждения одновременно ничего не дают, а
   мета-тег — лишняя строка в каждом ответе, про которую никто не вспомнит,
   если поменяется владелец кабинета.
   *Отвергнуто:* добавить мета-тег «на всякий случай». Он подтверждал бы того,
   чей код в нём записан, и при смене владельца стал бы ложным.

2. **Отправка карты — вручную владельцем.** Это одно действие в кабинете;
   автоматизация через API Вебмастера потребовала бы хранить OAuth-токен
   владельца ради операции, которая выполняется один раз.
   *Отвергнуто:* интеграция с API Вебмастера.

3. **Отправка — после выкатки полной карты на прод.** Иначе первая обработка
   карты Вебмастером увидит шесть страниц без статей.
