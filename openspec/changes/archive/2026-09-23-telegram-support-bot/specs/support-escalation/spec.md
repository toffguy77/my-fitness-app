## ADDED Requirements

### Requirement: Создание обращения к оператору

Обращение к оператору SHALL создаваться при явной просьбе пользователя, при отказе бота ответить и при повторном непонимании вопроса. Обращение MUST содержать историю диалога и, при наличии связи, данные заявки или аккаунта.

#### Scenario: Явная просьба позвать человека

- **WHEN** пользователь просит соединить с человеком
- **THEN** создаётся обращение к оператору
- **AND** пользователю сообщается, что вопрос передан

#### Scenario: Отказ бота ответить

- **WHEN** бот не нашёл ответа в базе знаний и пользователь согласился передать вопрос человеку
- **THEN** создаётся обращение с текстом вопроса и историей диалога

#### Scenario: Обращение содержит контекст заявки

- **WHEN** создаётся обращение в чате, связанном с заявкой
- **THEN** обращение содержит шаг онбординга и введённые параметры

### Requirement: Работа оператора с обращениями

Пользователь с ролью оператора поддержки SHALL видеть список открытых обращений, читать диалог, отправлять ответ и закрывать обращение. Доступ к обращениям пользователям без этой роли MUST быть запрещён.

#### Scenario: Просмотр списка обращений

- **WHEN** оператор запрашивает список обращений
- **THEN** возвращается постраничный список открытых обращений со временем создания и временем ожидания

#### Scenario: Доступ без роли

- **WHEN** пользователь без роли оператора обращается к списку обращений
- **THEN** API отвечает статусом `403`

#### Scenario: Закрытие обращения

- **WHEN** оператор закрывает обращение
- **THEN** обращение исчезает из списка открытых
- **AND** сохраняется в истории

### Requirement: Доставка ответа оператора в Telegram

Ответ оператора SHALL доставляться в тот же чат Telegram, из которого поступило обращение, и MUST быть обозначен как ответ человека, а не бота.

#### Scenario: Оператор отвечает на обращение

- **WHEN** оператор отправляет ответ по обращению
- **THEN** сообщение доставляется в исходный чат Telegram
- **AND** содержит признак того, что отвечает человек

#### Scenario: Недоставленный ответ

- **WHEN** доставка ответа в Telegram завершилась ошибкой
- **THEN** обращение не закрывается
- **AND** оператору отображается признак неуспешной доставки

### Requirement: Оповещение о новом обращении

При создании обращения SHALL формироваться оповещение операторам.

#### Scenario: Создано обращение

- **WHEN** создаётся новое обращение к оператору
- **THEN** операторам отправляется оповещение о нём
