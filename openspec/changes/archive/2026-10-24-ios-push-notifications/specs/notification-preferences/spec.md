## MODIFIED Requirements

### Requirement: Тихое время

Пользователь SHALL иметь возможность задать интервал суток, в который push не доставляется со звуком. Интервал MUST интерпретироваться в часовом поясе пользователя. Web Push, выпавший на этот интервал, MUST доставляться в начале ближайшего разрешённого времени, а не отменяться. Пуш на устройство iOS в этот интервал MUST доставляться сразу с `interruption-level: passive` и без звука.

#### Scenario: Событие в тихое время

- **WHEN** уведомление создано во время, попадающее в тихий интервал пользователя
- **THEN** доставка через Web Push откладывается до окончания интервала
- **AND** уведомление в приложении создаётся немедленно

#### Scenario: Событие в тихое время на iPhone

- **WHEN** уведомление создано в тихий интервал пользователя с устройством iOS
- **THEN** APNs-сообщение отправлено сразу с `interruption-level` равным `passive` и без `sound`

#### Scenario: Смена часового пояса

- **WHEN** пользователь изменил часовой пояс
- **THEN** тихий интервал применяется в новом часовом поясе

## ADDED Requirements

### Requirement: Сообщения чата — отдельный тип в матрице

Матрица предпочтений SHALL содержать тип `chat_message` с единственным настраиваемым каналом push, разрешённым по умолчанию. Почта для этого типа MUST NOT предлагаться.

#### Scenario: Чтение предпочтений

- **WHEN** пользователь запрашивает `GET /api/v1/notifications/delivery-preferences`
- **THEN** ответ содержит тип `chat_message` с каналом push, включённым по умолчанию
- **AND** для него нет почтового канала
