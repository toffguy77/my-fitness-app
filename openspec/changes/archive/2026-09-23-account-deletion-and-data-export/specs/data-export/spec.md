## ADDED Requirements

### Requirement: Запрос выгрузки персональных данных

Аутентифицированный пользователь SHALL иметь возможность запросить выгрузку своих данных. Выгрузка формируется асинхронно. Одновременно активной MUST быть не более одной выгрузки на пользователя, и не более одной выгрузки в сутки.

#### Scenario: Запрос выгрузки

- **WHEN** пользователь вызывает `POST /api/v1/users/me/export`
- **THEN** API отвечает статусом `202` и идентификатором выгрузки
- **AND** создаётся запись выгрузки в состоянии подготовки

#### Scenario: Повторный запрос при активной выгрузке

- **WHEN** пользователь запрашивает выгрузку при наличии незавершённой
- **THEN** API отвечает статусом `409`

#### Scenario: Превышение суточного лимита

- **WHEN** пользователь запрашивает вторую выгрузку в течение суток
- **THEN** API отвечает статусом `429`

### Requirement: Состав выгрузки

Архив выгрузки SHALL содержать данные профиля, телесного профиля и настроек, записи дневника питания и воды, метрики и историю веса, задачи и недельные планы, недельные отчёты, переписку с куратором, уведомления и пользовательские продукты — в машиночитаемом формате, а также файлы пользователя.

#### Scenario: Структура архива

- **WHEN** выгрузка сформирована
- **THEN** архив содержит файлы в формате JSON по разделам данных
- **AND** архив содержит директорию с файлами пользователя из всех хранилищ
- **AND** архив содержит файл описания состава выгрузки на русском языке

### Requirement: Выдача выгрузки по одноразовой ссылке

Готовая выгрузка SHALL выдаваться аутентифицированному владельцу по ссылке, действующей не более 24 часов и не более одного скачивания.

#### Scenario: Скачивание готовой выгрузки

- **WHEN** владелец обращается к `GET /api/v1/users/me/export/{id}` для готовой выгрузки в пределах срока действия
- **THEN** API отдаёт архив
- **AND** выгрузка помечается скачанной

#### Scenario: Повторное скачивание

- **WHEN** владелец повторно обращается к уже скачанной выгрузке
- **THEN** API отвечает статусом `410`

#### Scenario: Обращение чужого пользователя

- **WHEN** пользователь обращается к выгрузке, принадлежащей другому пользователю
- **THEN** API отвечает статусом `403`

#### Scenario: Уведомление о готовности

- **WHEN** формирование выгрузки завершено успешно
- **THEN** пользователю создаётся уведомление о готовности выгрузки
