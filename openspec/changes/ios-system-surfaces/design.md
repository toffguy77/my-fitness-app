## Context

Расширение виджетов — отдельный процесс с жёсткими лимитами памяти и времени.

- **Токены.** Расширение читает access-токен из общей группы Keychain, но не
  обновляет сессию (`ios-app-foundation`): гонка двух процессов за
  refresh-токен заканчивается `session_ended`.
- **Обновления.** Виджеты получают их по таймлайну и по
  `WidgetCenter.reloadTimelines` из приложения.

## Goals / Non-Goals

**Goals:**
- Остаток на виджете совпадает с «Сегодня» с задержкой не больше нескольких минут после изменения.
- «+ стакан» из виджета и Пункта управления не открывает приложение и не теряется без сети.

**Non-Goals:**
- Live Activities и Dynamic Island.
- Виджеты для Apple Watch и приложение для часов — следующим изменением.
- StandBy-макеты сверх стандартного поведения системы.

## Decisions

### Снимок дня в App Group вместо сети в расширении

После каждой загрузки «Сегодня» и каждого изменения приложение пишет снимок
`{date, remaining_kcal, eaten_kcal, goal_kcal, macros, water, updated_at,
role, attention_count, unread}` в файл App Group и вызывает
`reloadTimelines`.

- **Чтение.** Виджет читает только снимок.
- **Устаревание.** Снимок за прошлую дату показывается как «Нет данных за
  сегодня», а не вчерашним остатком.
- **Полночь.** Таймлайн добавляет запись на полночь по поясу профиля.

Отвергнуто:
- **Ходить в API из виджета на каждом таймлайне.** Лимит обновлений
  виджетов, батарея. При просроченном токене виджет без доступа к refresh
  покажет ошибку.

### Действие из виджета — оптимистично в снимок и в очередь

`AddWaterIntent` (`openAppWhenRun = false`):
1. увеличивает воду в снимке;
2. ставит изменение в общую очередь с `Idempotency-Key`;
3. пробует отправить его с текущим access-токеном;
4. при `401` оставляет изменение в очереди для приложения.

Виджет обновляется сразу из снимка.

Отвергнуто:
- **Открывать приложение для каждого стакана.** Теряется смысл кнопки.

### Пункт управления и кнопка «Действие»

`ControlWidgetButton`:
- «Добавить стакан воды» — `AddWaterIntent`;
- «Еда по фото» и «Штрихкод» — `OpenFoodLoggingIntent(method:)` с
  `openAppWhenRun = true`.

Кнопку «Действие» пользователь назначает в настройках iPhone на любой из
этих элементов. Отдельного кода не нужно.

### Фразы Siri на русском

`AppShortcutsProvider` объявляет фразы с `\(.applicationName)`. Название
приложения — «Взвешено».

`RemainingCaloriesIntent` отвечает голосом и карточкой:
«Осталось 1 923 килокалории. Белки — 49 граммов».
`LogWeightIntent(value:)` принимает число с запятой и проверяет границы
0,1–500.

Отвергнуто:
- **Только «Быстрые команды» без фраз.** Пользователь не узнает о
  возможности, пока не соберёт команду сам.

### Виджет куратора

Маленький виджет показывает «Требуют внимания: N» и «Непрочитанные: M» из
снимка. Нажатие открывает «Клиенты». Галерея виджетов показывает все виджеты всем: WidgetKit не фильтрует их по роли. Поэтому виджет чужой роли показывает «Доступно клиентам» или «Доступно кураторам».

## Risks / Trade-offs

- [Снимок устаревает, если приложение давно не открывалось] → виджет показывает время обновления; фоновый пуш об изменении непрочитанного (`ios-push-notifications`) и `BGAppRefreshTask` обновляют снимок в фоне.
- [Двойной стакан при повторном нажатии] → нажатие в виджете показывает новое значение сразу; каждое нажатие — отдельное изменение с собственным ключом, так что два нажатия — два стакана, как задумано.
