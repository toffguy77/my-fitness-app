## ADDED Requirements

### Requirement: Элементы Пункта управления

Расширение SHALL объявлять элементы управления «Добавить стакан воды», «Еда по фото» и «Штрихкод»; «Добавить стакан воды» MUST выполняться без открытия приложения, два других MUST открывать лист «Записать еду» на соответствующем способе.

#### Scenario: Штрихкод из Пункта управления

- **WHEN** нажат элемент «Штрихкод»
- **THEN** приложение открывается сразу на сканере штрихкода

### Requirement: Вода без открытия приложения и без сети

`AddWaterIntent` SHALL увеличивать воду в снимке, ставить изменение в общую очередь с собственным `Idempotency-Key` и пытаться отправить его с текущим access-токеном из Keychain; при отсутствии сети или просроченном токене изменение MUST оставаться в очереди и досылаться приложением (передний план, фоновое обновление, появление сети). Расширение MUST NOT обновлять сессию и стирать данные аккаунта (`ios-app-foundation`, «Одна очередь обновления сессии»): `401` — тоже «оставить приложению».

#### Scenario: Нажатие в режиме полёта

- **WHEN** «Добавить стакан воды» нажат без сети
- **THEN** виджет показывает на стакан больше
- **AND** после появления сети и открытия приложения стакан записан на сервере один раз

#### Scenario: Просроченный токен

- **WHEN** «Добавить стакан воды» нажат, а сервер отвечает `401 token_expired`
- **THEN** изменение остаётся в очереди, `native/refresh` не вызывается, сессия в Keychain не тронута

#### Scenario: Вода выключена куратором

- **WHEN** в снимке вода выключена (`enabled: false`)
- **THEN** интент отвечает «Куратор пока не задал цель по воде», изменение не создаётся
