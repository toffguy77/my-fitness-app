## ADDED Requirements

### Requirement: Белый список зеркалируемых событий объявлен в одном месте

Перечень событий, зеркалируемых во внешний счётчик, SHALL быть объявлен рядом со словарём продуктовых событий и SHALL быть единственным источником этого перечня.

#### Scenario: Имя добавлено в белый список

- **WHEN** имя события добавляется в белый список
- **THEN** оно присутствует в словаре продуктовых событий
- **AND** оно не объявлено как серверное

#### Scenario: Имя удалено из словаря

- **WHEN** имя события удаляется из словаря, оставаясь в белом списке
- **THEN** проверка завершается ошибкой

### Requirement: Свойства продуктовых событий не покидают приложение

Свойства продуктовых событий MUST NOT передаваться во внешние сервисы аналитики ни в каком виде.

#### Scenario: Попытка передать свойства

- **WHEN** код зеркалирования получает событие со свойствами
- **THEN** наружу уходит только имя цели

#### Scenario: Запрет проверяется автоматически

- **WHEN** тест сверяет вызов зеркалирования с передаваемыми аргументами
- **THEN** передача чего-либо кроме имени цели завершается ошибкой
