## Requirements
### Requirement: Разговор с ботом без аккаунта

Посетитель без аккаунта SHALL иметь возможность начать разговор с ботом из браузера. Начало разговора MUST выдавать посетителю токен, которым он опознаётся в последующих обращениях.

#### Scenario: Начало разговора

- **WHEN** посетитель без аккаунта открывает виджет и отправляет первое сообщение
- **THEN** создаётся разговор с каналом «веб»
- **AND** посетитель получает токен разговора
- **AND** на сервере хранится только хэш токена

#### Scenario: Продолжение разговора

- **WHEN** посетитель отправляет следующее сообщение с тем же токеном
- **THEN** сообщение добавляется в тот же разговор

#### Scenario: Возврат на страницу

- **WHEN** посетитель возвращается на страницу, сохранив токен
- **THEN** он видит историю своего разговора

#### Scenario: Чужой или поддельный токен

- **WHEN** предъявлен токен, не выданный системой
- **THEN** доступ к разговору не предоставляется

### Requirement: Ограничения публичного разговора

Разговор в веб-канале SHALL быть ограничен по частоте обращений, длине сообщения и числу сообщений в разговоре.

#### Scenario: Превышение частоты обращений

- **WHEN** число обращений с одного адреса превышает установленный предел
- **THEN** обращение отклоняется
- **AND** вызов модели не выполняется

#### Scenario: Слишком длинное сообщение

- **WHEN** посетитель отправляет сообщение длиннее установленного предела
- **THEN** сообщение отклоняется с объяснением

#### Scenario: Исчерпан дневной потолок вызовов модели

- **WHEN** дневной потолок вызовов модели исчерпан
- **THEN** посетитель получает честный ответ о временной невозможности ответить
- **AND** ему предлагается позвать человека

### Requirement: Переход в Telegram из виджета

Из виджета SHALL быть доступен переход в Telegram, переносящий сохранённую заявку посетителя.

#### Scenario: Переход с сохранённой заявкой

- **WHEN** посетитель, у которого сохранена заявка, выбирает переход в Telegram
- **THEN** открывается ссылка на бота с признаком заявки
- **AND** начатый в Telegram разговор оказывается привязан к той же заявке

#### Scenario: Переход без заявки

- **WHEN** посетитель без сохранённой заявки выбирает переход в Telegram
- **THEN** открывается ссылка на бота без признака заявки

#### Scenario: Бот в Telegram не настроен

- **WHEN** в развёртывании не настроен Telegram-бот
- **THEN** переход в Telegram не предлагается
- **AND** разговор в виджете остаётся доступен

### Requirement: Вызов человека из виджета

Посетитель SHALL иметь возможность позвать живого человека, не формулируя это боту.

#### Scenario: Посетитель зовёт человека

- **WHEN** посетитель выбирает вызов человека
- **THEN** разговор переходит в состояние ожидания оператора
- **AND** разговор появляется в очереди оператора наравне с разговорами из Telegram

#### Scenario: Бот не знает ответа

- **WHEN** бот не находит ответа в базе знаний
- **THEN** он сообщает, что не знает
- **AND** разговор переходит в состояние ожидания оператора

### Requirement: Ответ оператора в веб-канале

Ответ оператора в веб-разговоре SHALL становиться доступен посетителю при следующем обращении с его токеном.

#### Scenario: Посетитель читает ответ оператора

- **WHEN** оператор отвечает в веб-разговор
- **AND** посетитель обращается за сообщениями со своим токеном
- **THEN** он получает ответ оператора

#### Scenario: Посетитель не вернулся

- **WHEN** оператор отвечает в веб-разговор
- **AND** посетитель не возвращается
- **THEN** попытка отправки в Telegram не выполняется
