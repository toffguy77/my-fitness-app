# article-authorship Specification

## Purpose
Определяет, кем подписаны публичные статьи: эксперт с квалификацией и фото в видимом тексте и в разметке Person, страница автора, и запрет показывать внутреннее имя учётной записи, от которой статья заведена.

## Requirements

### Requirement: Публичная статья подписана экспертом

Страница публичной статьи SHALL показывать автора «Сергей Бурцев» с
квалификацией «Спортивный практикующий тренер, мастер спорта по тяжёлой
атлетике» и ссылкой на страницу автора. Внутреннее имя учётной записи, от которой
заведена статья, MUST NOT показываться на публичной странице.

#### Scenario: Блок автора

- **WHEN** отрендерена публичная статья
- **THEN** под заголовком есть ссылка «Сергей Бурцев» на `/avtor/sergey-burcev` и строка квалификации

#### Scenario: Имя учётной записи скрыто

- **WHEN** API отдаёт статью с `author_name` «Красный Кот»
- **THEN** на странице нет текста «Красный Кот»

#### Scenario: Фото нет

- **WHEN** фото автора не задано
- **THEN** блок автора показывает инициалы и не содержит битого изображения

#### Scenario: Фото задано

- **WHEN** фото автора задано
- **THEN** блок автора содержит изображение с альтернативным текстом «Сергей Бурцев»

### Requirement: Автор статьи размечен как человек

JSON-LD статьи SHALL указывать `author` типа `Person` с `name`, `jobTitle` и `url`
страницы автора и SHALL указывать `image` только при заданном фото.

#### Scenario: Разметка статьи

- **WHEN** отрендерена публичная статья
- **THEN** JSON-LD содержит `author.@type = Person`, `author.name = Сергей Бурцев`, `author.url = https://burcev.team/avtor/sergey-burcev`

#### Scenario: Без фото

- **WHEN** фото автора не задано
- **THEN** в `author` нет поля `image`

### Requirement: Страница автора

Страница `/avtor/sergey-burcev` SHALL быть открыта для индексации и SHALL
содержать `h1` с именем автора, квалификацию, ссылки на его публичные статьи и
JSON-LD `ProfilePage` с `mainEntity` типа `Person`.

#### Scenario: Запрос без JavaScript

- **WHEN** страница автора запрашивается с выключенным JavaScript
- **THEN** документ содержит `h1` «Сергей Бурцев», квалификацию и ссылки на статьи

#### Scenario: Разметка профиля

- **WHEN** страница автора отрендерена
- **THEN** JSON-LD содержит `@type = ProfilePage` и `mainEntity.@type = Person`
