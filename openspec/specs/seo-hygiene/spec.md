# seo-hygiene Specification

## Purpose
Определяет технические условия корректной индексации публичных страниц: безопасный вывод JSON-LD, настоящий 404, предел размера публичной ленты, закрытие служебных страниц по токену и хлебные крошки статьи.

## Requirements

### Requirement: Разметка JSON-LD не может закрыть свой блок

Компонент вывода JSON-LD SHALL экранировать символы `<`, `>`, `&`, U+2028 и
U+2029 так, чтобы данные не могли закрыть элемент `<script>`. Экранированный
вывод MUST разбираться как JSON в те же данные.

#### Scenario: Заголовок с закрывающим тегом

- **WHEN** в данных есть строка `</script><img src=x onerror=alert(1)>`
- **THEN** вывод не содержит `</script` и `<img`, а разбор вывода как JSON возвращает исходную строку

### Requirement: Несуществующая статья отвечает 404

Запрос `/content/<slug>`, по которому публичный API не нашёл статью, SHALL
получать ответ со статусом `404`.

#### Scenario: Неизвестный slug

- **WHEN** запрошен `/content/takoy-stati-net`
- **THEN** ответ имеет статус `404`

#### Scenario: Ошибка API

- **WHEN** публичный API ответил ошибкой сервера
- **THEN** страница не отвечает статусом `404`

### Requirement: Публичная лента ограничивает размер страницы

Публичная лента статей SHALL возвращать не более 100 карточек за запрос,
какой бы `limit` ни был передан.

#### Scenario: Слишком большой limit

- **WHEN** запрошена публичная лента с `limit=100000`
- **THEN** сервис запрашивает у базы не более 100 строк

### Requirement: Служебные страницы по токену не индексируются

Страница отписки SHALL быть помечена `noindex, nofollow`.

#### Scenario: Отписка

- **WHEN** проверяются метаданные `/unsubscribe`
- **THEN** `robots.index` и `robots.follow` равны `false`

### Requirement: Статья размечена хлебными крошками

Страница публичной статьи SHALL содержать JSON-LD `BreadcrumbList` из трёх
элементов: главная страница, лента статей, статья.

#### Scenario: Хлебные крошки

- **WHEN** отрендерена публичная статья
- **THEN** JSON-LD содержит `BreadcrumbList` с адресами `https://burcev.team`, `https://burcev.team/content` и каноническим адресом статьи
