# ios-curator-chat Specification

## Purpose
Список переписок, переписка, КБЖУ по фото. Возможность введена изменением `ios-curator-app` (архив `openspec/changes/archive/2026-10-24-ios-curator-app`).

## Requirements

### Requirement: Список переписок

«Чаты» SHALL показывать `GET /conversations`: сначала с непрочитанным, затем по времени последнего сообщения; превью — текст до 50 символов или «Фото», «Файл», «КБЖУ запись», время — «только что», «N мин назад», «N ч назад», «вчера» или дата.

#### Scenario: Порядок

- **WHEN** у клиента A непрочитанное вчера, а у клиента B прочитанное сегодня
- **THEN** A выше B

### Requirement: Переписка открывается по клиенту

Переписка с клиентом SHALL открываться запросом `GET /conversations/by-participant/:userId`; при `404` MUST показываться «Переписка с клиентом не найдена» с кнопкой «Открыть карточку клиента», а не бесконечная загрузка.

#### Scenario: Переписки нет

- **WHEN** сервер отвечает `404`
- **THEN** показано «Переписка с клиентом не найдена»

### Requirement: КБЖУ по фото клиента

Под каждым фото, отправленным клиентом, SHALL быть кнопка «Ввести КБЖУ», открывающая лист с полями «Блюдо», «Приём пищи», «Вес, г», «Калории», «Белки, г», «Жиры, г», «Углеводы, г»; приём по умолчанию MUST выбираться по времени фото, а ошибка отправки MUST оставлять лист открытым с введёнными значениями.

#### Scenario: Фото в 20:14

- **WHEN** куратор открывает лист под фото, отправленным в 20:14
- **THEN** выбран приём «Ужин»

#### Scenario: Успех

- **WHEN** куратор отправляет КБЖУ
- **THEN** отправлен `POST /conversations/:id/messages/:msgId/food-entry`
- **AND** в переписке появилась карточка «Записано в дневник»

### Requirement: Ответ из пуша

Пуш `chat_message` у куратора SHALL предлагать действие «Ответить» с полем ввода; ответ MUST отправляться в переписку из `target.ids.conversation_id` через очередь изменений без открытия приложения.

#### Scenario: Ответ с экрана блокировки

- **WHEN** куратор отвечает «Принято» из уведомления
- **THEN** сообщение «Принято» отправлено в переписку, приложение не открывалось
