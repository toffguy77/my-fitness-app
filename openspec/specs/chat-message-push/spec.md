# chat-message-push Specification

## Purpose
Пуш о новом сообщении чата получателю без активного соединения. Возможность введена изменением `ios-push-notifications` (архив `openspec/changes/archive/2026-10-24-ios-push-notifications`).

## Requirements

### Requirement: Сообщение чата пушится получателю без соединения

Сервер SHALL после сохранения сообщения в переписке — написанного в приложении, записи КБЖУ от куратора или сообщения, пришедшего из Telegram-моста, — создавать задание push типа `chat_message` для получателя, у которого нет открытого WebSocket-соединения, если тип `chat_message` разрешён для push в его предпочтениях. Строка в списке уведомлений MUST NOT создаваться.

#### Scenario: Клиент не в приложении

- **WHEN** куратор отправляет сообщение клиенту без открытого соединения
- **THEN** создаётся задание push `chat_message` с `target {kind: "chat", ids: {conversation_id, participant_id}}`
- **AND** `GET /api/v1/notifications` не содержит новой записи

#### Scenario: Клиент в приложении

- **WHEN** у получателя открыто WebSocket-соединение
- **THEN** задание push не создаётся

#### Scenario: Получатель отключил пуш о сообщениях

- **WHEN** у получателя push для `chat_message` выключен
- **THEN** задание push не создаётся

### Requirement: Прочитанное не пушится

Перед отправкой задания `chat_message` сервер SHALL проверять, не прочитал ли получатель переписку после этого сообщения, и в этом случае MUST отменять задание.

#### Scenario: Прочитал в вебе до отправки

- **WHEN** задание ждёт отправки, а получатель открыл переписку в браузере
- **THEN** пуш не отправляется и задание помечено отменённым

### Requirement: Текст сообщения на экране блокировки — по настройке

Тело пуша `chat_message` SHALL содержать текст сообщения, если у получателя включено «Показывать текст сообщений» (по умолчанию включено), и «Новое сообщение от {имя}» — если выключено.

#### Scenario: Настройка по умолчанию

- **WHEN** новый пользователь получает сообщение «Белок держите отлично»
- **THEN** тело пуша — «Белок держите отлично»

#### Scenario: Текст скрыт

- **WHEN** у получателя выключено «Показывать текст сообщений»
- **THEN** тело пуша — «Новое сообщение от Анна», текста сообщения в нагрузке нет

### Requirement: Пуш сообщения группируется по переписке

Пуш `chat_message` SHALL иметь `aps.thread-id = "conversation:<id>"` и категорию `CHAT_MESSAGE`; заголовок — имя отправителя, тело — текст сообщения, обрезанный до 180 символов, либо «Фото», «Файл» или «КБЖУ запись» для вложений.

#### Scenario: Фото от клиента

- **WHEN** клиент отправляет фото куратору
- **THEN** тело пуша — «Фото»
- **AND** `thread-id` равен `conversation:<id переписки>`
