# Иконка «Взвешено» для iOS

Направление «Шкала»: дуга весов, стрелка ровно посередине — норма взвешена.
Цвета — из дизайн-системы (`packages/design-tokens`): бумага `#F6F1E8`,
дорожка `#EADFCF`, терракота `#B8492F`, чернила `#2A2118`; в тёмной —
`#E58A6C` и `#F3EADC`.

## Xcode (iOS 18+)
Перетащите `AppIcon.appiconset` в `Assets.xcassets` вместо пустого AppIcon.
Внутри один размер 1024×1024 — Xcode сам строит остальные:
- `AppIcon-1024.png` — светлая, без прозрачности, без скруглений (маску накладывает система);
- `AppIcon-1024-dark.png` — тёмная, фон прозрачный: тёмную подложку рисует iOS;
- `AppIcon-1024-tinted.png` — тонированная, оттенки серого на чёрном.

## iOS 26 (Liquid Glass)
В `svg/layers/` — те же элементы по слоям: фон, дорожка, заполненная дуга с
меткой, стрелка. Импортируйте их в Icon Composer (Xcode 26) — стекло и блики
система наложит на каждый слой отдельно. До этого `AppIcon.appiconset`
работает и на iOS 26.

## Исходники
`svg/icon-light.svg`, `icon-dark.svg`, `icon-tinted.svg` — векторные
источники PNG. Текста в иконке нет, шрифты не нужны.
