Лист ответов анкеты «Конфиденциальность приложения» (App Privacy) в App Store Connect
для «Взвешено» (team.burcev.app), версия 1.0.0.

Анкету заполняет человек: App Store Connect → приложение → App Privacy. Lane `metadata`
её не загружает. Ответы сверены с кодом (Vzvesheno/App/Telemetry.swift, VzveshenoKit,
project.yml), манифестом Vzvesheno/Resources/PrivacyInfo.xcprivacy (его типы сверяет
VzveshenoTests/ComplianceTests) и политикой https://burcev.team/legal/privacy
(разделы 2, 2-а, 9-а). Анкета может объявлять больше, чем манифест, но не меньше.

Отслеживания (tracking) нет: сторонних SDK рекламы и аналитики нет, IDFA не
используется, запроса App Tracking Transparency нет, NSUserTrackingUsageDescription
отсутствует. Единственный сторонний пакет — Sentry, только отчёты о сбоях.

ШАГ 4. Для каждого отмеченного типа — три вопроса подряд
=====================================================================
Порядок у Apple: цель (purposes) → связан ли с пользователем (linked) →
используется ли для отслеживания (tracking).

Тип                      | Purposes            | Linked to you | Used for tracking
-------------------------|---------------------|---------------|------------------
Name                     | App Functionality   | Yes           | No
Email Address            | App Functionality   | Yes           | No
Other User Contact Info  | App Functionality   | Yes           | No
Health                   | App Functionality   | Yes           | No
Fitness                  | App Functionality   | Yes           | No
Photos or Videos         | App Functionality   | Yes           | No
Other User Content       | App Functionality   | Yes           | No
User ID                  | App Functionality   | Yes           | No
Device ID                | App Functionality   | Yes           | No
Product Interaction      | Analytics           | Yes           | No
Crash Data               | App Functionality   | Yes           | No

Пояснения:
- Целей Third-Party Advertising, Developer's Advertising or Marketing, Product
  Personalization и Other Purposes не отмечать нигде. Данные Здоровья — только
  App Functionality (App Review 5.1.3: не для рекламы, маркетинга и data mining).
- Product Interaction связан с пользователем: после входа события посетителя
  привязываются к аккаунту (analytics_identities); при удалении аккаунта связь
  удаляется, а события обезличиваются.
- Crash Data связаны с пользователем: Telemetry.identify передаёт в Sentry
  числовой id и роль. Цель App Functionality у Apple включает устранение сбоев.
  Данных Здоровья, дневника, сообщений, почты и имени в отчётах нет
  (sendDefaultPii = false; без снимков экрана, иерархии видов, сетевых крошек и
  трассировки; beforeSend убирает request).
- Tracking = No везде: данные не объединяются с чужими данными для рекламы и не
  передаются брокерам данных.

=====================================================================
ШАГ 5. Проверка перед публикацией
=====================================================================
- Превью ярлыка: «Data Linked to You» — Contact Info, Health & Fitness, User
  Content, Identifiers, Usage Data, Diagnostics. «Data Used to Track You» и
  «Data Not Linked to You» — пусто.
- Расхождение с манифестом: в PrivacyInfo.xcprivacy нет User ID, Device ID и Other
  User Contact Info. Анкета их объявляет; манифест стоит дополнить
  (NSPrivacyCollectedDataTypeUserID, NSPrivacyCollectedDataTypeDeviceID,
  NSPrivacyCollectedDataTypeOtherUserContactInfo) вместе с ComplianceTests.
